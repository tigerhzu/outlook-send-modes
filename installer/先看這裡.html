把寄信模式加入自己的 Outlook

如果這台電腦已顯示「本機服務正常」，直接從第 2 步開始。

1. 新電腦先安裝本機服務

在 Windows 10／11 x64 將 ZIP 全部解壓縮，再執行同資料夾的 SendModes-Setup-1.6.2.exe。若 Windows 詢問是否信任安裝程式剛建立的 localhost 憑證，請核對後確認。等診斷顯示「本機服務正常」再關閉視窗。

2. 在要用的信箱加入增益集

先看桌面 Outlook 撰寫郵件時的寄件者地址。開啟下方頁面後，確認瀏覽器登入的是同一個信箱；若自動登入其他帳號，可在瀏覽器的私人視窗開啟 https://aka.ms/olksideload 再登入。

開啟 Microsoft 增益集安裝頁

  1. 選「我的增益集」（My add-ins），往下找到「自訂增益集」（Custom Addins）。若已列出「寄信模式」，直接到第 3 步。
  2. 選「新增自訂增益集」→「從檔案新增」（Add from File）。在剛解壓縮的資料夾選 manifest.xml，依提示完成安裝。

3. 在新草稿確認入口

回到 Windows 新版 Outlook，選剛才的信箱，按「新增郵件」→ 撰寫工具列的「應用程式」（Apps）→「寄信模式」。看到模式清單就測試完成，可直接關閉草稿。

找不到「從檔案新增」或「寄信模式」？

若帳號正確，卻缺少「從檔案新增」或出現權限錯誤，請將同包的 manifest.xml 交給 IT，請他們確認這個信箱可安裝自訂增益集，或部署給這個信箱。

若安裝頁已列出「寄信模式」，請在網頁版同一信箱開新草稿，查看「應用程式」。若網頁版看得到，重新開啟桌面 Outlook 再試。回報時請註明哪一步、哪個畫面看不到；若附截圖，請遮住信箱和郵件內容。
