## 架構（一句話）
同事 Outlook → HTTPS 開公司主機上的面板網頁 → Entra 公司帳號登入 → Node 範本服務驗證通行證 → 用憑證（Sites.Selected）到 SharePoint 讀 `catalog-state.json` → 同事插入目前草稿、自己寄出。

## 已回答 Hank 的問題
1. **要不要反向代理、要不要上 internet**：Node 只跑 HTTP，前面要有東西提供 HTTPS——公司主機用 IIS／nginx 反向代理；Azure App Service 自帶 HTTPS 不用代理。不一定要對外，只要同事裝置連得到；主機只需出站連 Microsoft 與 SharePoint。憑證建議用公司網域申請的公開憑證（Mac 才會信任）。
2. **放內網、人在外面會怎樣**：按鈕還在，面板打不開（網頁 `.html` 為 no-store，沒有本機副本），Outlook 寫信寄信不受影響，連 VPN 即恢復。公司範本不存本機；舊版 EXE（localhost）的個人範本不會自動搬，試行者要先移除舊版（同 AppId 會衝突）。
3. **Azure App Service 月費 / 範本快取到本機省錢**：Linux Basic B1 約 US$13–18／月（約台幣 400–600，依地區，以價格計算機為準）；F1 免費版不能掛自訂網域憑證。按開機時間計費、與連線次數無關，所以本機快取省不到錢；面板本身在主機上，離線也打不開；插入前必須向主機重新確認範本仍已發布（專案規則），不能完全不連。
